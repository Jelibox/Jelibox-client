Features

Less friction between image and insight.

Everything you need to annotate, inspect, train, and export without sending your dataset through a cloud service.

Label Assistant

Describe it, and Jelibox finds it

Pick YOLO-World to detect objects from plain-text prompts, no training needed, and map each prompt to your own classes (for example “white horse” and “black horse” both become horse). Or switch to the model you trained in the workspace. Predictions merge with your existing boxes and skip anything that overlaps.

Privacy

Local by design

Your images, labels, and models stay on the machine you control.

Precision

Box + polygon tools

Edit coordinates directly with handles, zoom, visibility controls, and class management.

Pipeline

Train in context

Go from annotations to Ultralytics training without leaving your workspace, and without duplicating your source images.

Output

Flexible exports

Start locally

Install once. Keep working.

One command, no git needed. It downloads the newest release and sets everything up. Run it again later to update; your datasets and models are never touched.

Windows

Open PowerShell and paste:

irm https://raw.githubusercontent.com/Jelibox/Jelibox-client/main/install.ps1 | iex

Jelibox gets its own Python (via uv) inside its folder; yours is never touched. Windows asks for administrator permission only if the Visual C++ runtime is missing.

Linux

Open a terminal and paste:

curl -fsSL https://raw.githubusercontent.com/Jelibox/Jelibox-client/main/install.sh | bash

Jelibox gets its own Python (via uv) inside its folder; yours is never touched. It asks for your sudo password only if the OpenCV system libraries (libGL, GLib) are missing.

The installer asks whether this computer has a discrete NVIDIA graphics card and installs the CUDA or the smaller CPU-only PyTorch accordingly.

Prefer to read it first? install.ps1 and install.sh are short and open source.

Install manually with git instead

Linux

  1. Install git (if you haven't installed git) 
    sudo apt install git
  2. Clone this repository 
    git clone https://github.com/Jelibox/Jelibox-client.git
  3. Add access to linux installation script 
    chmod +x jelibox_linux_installation.bash
  4. Run Jelibox installation script 
    ./jelibox_linux_installation.bash

The installer needs sudo only if the OpenCV system libraries are missing. It installs uv if needed, downloads Jelibox's private Python, creates the jelibox/ virtual environment, installs dependencies, and creates a desktop launcher.

Windows

  1. Double-click jelibox_windows_installation.bat. Do not run it as administrator: it asks Windows for permission itself, only to install the Visual C++ runtime, and only when it is missing.
  2. Follow the installer prompts.
  3. Open the generated Jelibox.lnk shortcut.

The installer detects an NVIDIA GPU only to suggest an answer, then asks whether this computer has a discrete NVIDIA GPU and installs the matching PyTorch build. GPU detection does not guarantee that the installed PyTorch package has CUDA enabled.
